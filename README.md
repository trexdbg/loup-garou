# Thiercelieux — Assistant de maître du jeu

Application web hors ligne pour un maître du jeu et un seul joueur, inspirée des mécaniques du Loup-Garou. Contenus narratifs originaux, rôles cachés, alternance jour/nuit et scénarios de 30 à 60 minutes.

Voir `index.html` pour lancer l'application localement.
