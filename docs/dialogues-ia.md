# ChatGPT est le moteur principal de la partie

Ce document historique présentait une utilisation facultative de ChatGPT alors que l'application possédait son propre moteur local. Ce n'est plus l'architecture active.

**Le nouveau protocole officiel de jeu et de stockage est décrit dans [contrat-chatgpt.md](contrat-chatgpt.md).**

Une partie commence dans l'application par la création d'un ID et d'un JSON, puis continue exclusivement dans une conversation ChatGPT du projet Loup garou. Le MJ valide les décisions. ChatGPT joue les personnages et écrit seulement les scènes validées sur GitHub. L'application sert à consulter ces archives.

Les identités et solutions cachées restent dans la conversation privée : le dépôt GitHub public et GitHub Pages ne constituent pas un espace de secrets.
