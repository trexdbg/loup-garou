UNE AVENTURE CRÉÉE AVEC CHATGPT

Préparez votre partie. L'histoire se jouera dans ChatGPT.

Un MJ adulte, un seul joueur, des habitants joués par ChatGPT. Cette application génère uniquement un identifiant et un JSON de paramètres. Le MJ reste maître de l'histoire.

01

Le joueur et son aventure

Le joueur choisit son rôle, ou laisse ChatGPT le proposer au hasard.

02

Les cartes et les règles

Choisis un niveau, puis ajuste librement les rôles si nécessaire. Les véritables cartes sont utilisées quand leur visuel est vérifié.

🃏 Choisir les rôles autorisés

Le tirage éventuel est effectué dans ChatGPT, pas dans l'application. Décoche les cartes que tu ne souhaites pas utiliser.

Les pouvoirs officiels et leurs interactions sont arbitrés avec le MJ. Aucun personnage ne reçoit un pouvoir inventé par l'application.

03

Déroulement et assistance au MJ

Les décisions de l'enfant et les validations du MJ font avancer l'histoire, pas des boutons automatiques.

🎭 Le rôle de ChatGPT

Incarner les habitants, créer les dialogues, annoncer « Le village s'endort », organiser les appels de rôles, proposer les rebondissements et assister le MJ. Jamais révéler un secret au joueur sans justification ou validation.

04

Ambiance et affichage

Ces réglages sont transmis à ChatGPT. En consultation, l'application peut lire à haute voix les nouveaux dialogues publics, sans choisir d'actions ni révéler de secrets.

Les voix Gemini sont préparées côté GitHub Actions et jamais avec une clé API dans le navigateur. Les fichiers audio ne sont pas commités.

05

Créer le dossier de lancement

Un identifiant de partie et son JSON sont générés sur ton appareil. Rien n'est encore envoyé sur GitHub.

IDENTIFIANT DE PARTIE

Dans une conversation du projet ChatGPT Loup garou, colle de préférence le prompt complet. ChatGPT créera alors le prologue dans GitHub et attendra les instructions du MJ.

📋 Aide-mémoire du MJ : déroulement d’un débat
1. Écouter

Actualiser les dialogues et écouter la nouvelle scène. Le texte reste visible pour accompagner la lecture.

2. Jouer

Alex peut parler à n’importe quel personnage. Les PNJ débattent aussi entre eux ; personne ne décide pour Alex.

3. Continuer

Revenir dans ChatGPT avec la réponse d’Alex. Après validation du MJ, un nouvel échange est archivé et devient disponible à l’écoute.

4. Terminer le tour

Le MJ décide quand les débats se terminent. Le vote et la nuit ne démarrent jamais automatiquement.

🛡️ Accès privé au MJ, données publiques sur GitHub

L’interface est conçue pour le maître du jeu uniquement. Les archives et rôles stockés dans ce dépôt public restent accessibles sur GitHub : la régie n’est pas un contrôle d’accès. Elle prépare des consignes pour ChatGPT, sans jamais jouer de décision automatiquement.
